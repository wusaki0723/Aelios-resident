# 测试

住户的测试分两种：要起本地 Worker 的（`test/run.mjs`，按阶段跑），和不用起 Worker、直接测某一块代码的（`test/*.mjs`）。服务商、Telegram、Aelios 全是假的，不花钱，也不用登录 Cloudflare。

## 怎么跑

```sh
npm install
node test/mock-server.mjs &                                    # 假 Telegram 和假 Aelios，端口 9999
NO_PROXY=127.0.0.1 npx wrangler dev --config wrangler.test.jsonc --port 8787 &
NO_PROXY=127.0.0.1 node test/run.mjs main
```

`wrangler.test.jsonc` 用脚本模型（`FAKE_MODEL=true`），回什么由 `src/fake-model.ts` 按你发的话决定。

`test/run.mjs` 后面跟阶段名，每个阶段要一个刚起的 Worker（先删 `.wrangler/state`）。有的阶段要带变量起 Worker，见 `test/run.mjs` 开头：

| 阶段 | 测什么 |
| --- | --- |
| `main` | 主流程（默认） |
| `checkin` | 主动找你（起 Worker 时带 `--var CHECKIN_SCHEDULE:"every 1 minute"`） |
| `idle` | 空闲交接信（带 `--var LETTER_IDLE_MINUTES:0.05`） |
| `crash-1`、`crash-2` | 回到一半进程被杀 |
| `migrate` | 旧的 `MODEL` 变量搬进网页设置（带 `--var MODEL:fake`） |
| `custom` | 没接 Aelios 时走中转（带 `--var AELIOS_URL:`） |
| `mcp`、`mcp-2` | 接别的 MCP，重启后接回来 |
| `stickers` | 表情包 |
| `voice` | 语音条 |
| `tasks` | 叫云端 Claude Code 干活 |
| `tasks-quiet` | 云端的活没回音（带 `--var CLOUD_TASK_QUIET_MINUTES:0.05`） |
| `sites` | 带钥匙的网站 |
| `heartbeat` | 心跳（带 `--var LETTER_IDLE_MINUTES:0.05 --var KEEP_RECENT_TOKENS:100000 --var ALARM_MINUTE_SECONDS:0.05`） |
| `alarms` | 它自己定的闹钟（带 `--var ALARM_MINUTE_SECONDS:0.05`，一分钟只算 3 秒） |

不用起 Worker 的，直接 `node test/<名字>.mjs`：

| 文件 | 测什么 |
| --- | --- |
| `web.mjs` | 读网页 |
| `claude-run.mjs` | 发给 Claude 前的整理 |
| `history.mjs` | 网页上思考和工具的折叠、计数 |
| `history-worker.mjs` | 本地 Worker 上的实时思考和工具记录（要起 Worker） |
| `mini-app.mjs` | Mini App 进门（加 `worker` 再连本地 Worker 测一遍） |
| `fold.mjs` | 交接信收哪些聊天 |
| `via-aelios.mjs` | 从 Aelios 过的规矩 |
| `learn.mjs` | 搜网后存知识 |
| `mcp-servers.mjs` | 接别的 MCP |
| `stickers.mjs` | 表情包 |
| `voice.mjs` | 语音条 |
| `cloud-tasks.mjs` | 云端 Claude Code 的单子、回报和记录 |
| `site-keys.mjs` | 带钥匙的网站：网站和钥匙怎么认、哪个地址带哪把 |
| `web-ui.mjs` | 网页门和设置页 |
| `cache-window.mjs` | 缓存窗口什么时候换、写信那一轮的缓存标记、开机包的文字 |
| `alarms.mjs` | 闹钟的写法、下次什么时候响、心跳和响铃那一轮的提示 |

## 测过什么

本地用假 Telegram、假 Aelios、脚本模型跑 `test/run.mjs`：

- 主流程 33 项全过：错 secret 拒绝；陌生人和群聊不回；两个气泡和时间戳；正在输入；重发去重；开机包进系统提示（只有日记，没有珍贵原话和黑话）；缓存热着时开机包不重取、写完交接信后的下一句重取一次；`memory_recall` 打到 Aelios；`memory_remember` 走 Aelios 的 MCP；`memory_notebook` 读写小本本也走 MCP，长页整页拿回来不截（截了再整页重写会丢尾巴）；`web_fetch` 本机地址拒读；连发三条并成一轮；发的照片模型收到的是图（下载不了的还是一行附件说明），网页上显示「[图片]」；`/status`、`/letter`、`/handoff`（写信后对话里带着信；写信那一轮发给模型的前文和上一轮一字不差，所以吃得到缓存；那一轮缓存标记不在最后，留在上一轮她那句的最后一块上，所以不往缓存里写；经 Aelios 写信时也查了发出去的请求就是这样）；网页门没钥匙进不去；网页看得到 Telegram 的对话和交接信；网页上说的话在网页回、不发到 Telegram；心形按钮存进珍贵；没填人设时用默认那句；网页上存了人设，下一条 Telegram 消息就按新人设回；人设超过 3 万字拒收；旧版本留着，存空的回到默认；每轮都带 Anthropic 缓存标记（1 小时）；模型在网页上换，写错或调不通的不换，换成功的记进「最近用过」；接了 Aelios 时聊天从 Aelios 过（`anthropic/…` 走 Messages、带 Aelios 的 key 和缓存标记，之前几轮的思考块不发回去，住户自己不搜也不记），试调和交接信那一轮标成不是她说的，Aelios 说不是主模型的不换，换上之后才被拿出主模型的，网页和 `/status` 会说「没记下来」，`@cf/…` 换成 `workers-ai/@cf/…` 走 chat completions；设置页：key 不出现在页面上，时区、数字（`Infinity`、`1e309` 也算错）、选项、网址、排不上的定时都不收，填了身份下一句就以这个身份过，`TG_ALLOWED` 改成别人后她的消息不回、清掉又回，页面上存的 Aelios key 优先于 Worker 里的。另外单独测了旧的 `MODEL` 变量会搬到网页设置里。
- 缓存窗口（`node test/cache-window.mjs`）4 项：缓存时长 1 小时或 5 分钟；超过缓存时长没用过、写完交接信、还没有窗口时才换窗口，17:40 开的窗口到 23:40 只要中间一直有人说话就不换；写信那一轮的缓存标记打在写信提示前面最后一条不是工具结果的消息上，别的消息不动，缓存过期了就一个标记都不打；开机包只有最近一天的日记、带日期，没有珍贵原话和黑话，太长截断。
- 定时：每分钟一次的定时，第一次主动发了两个气泡并记进 Aelios，第二次模型回 SKIP，什么都没发。
- 空闲交接信：把空闲时间调成 3 秒，聊 3 轮后自己写了信：没发 Telegram、记进 Aelios、网页上看得到信、写信的那一问一答撤掉了、前文和上一轮一字不差、缓存标记留在上一轮那句；之后再说一句会再写一封，不说话就不再写。
- 没接 Aelios 时走中转（`--var AELIOS_URL:`，`node test/run.mjs custom`）：OpenAI 格式先试调再换上，带着 key 回话；在设置页把格式改成 `anthropic`，下一句就走 Messages：带着 key、每轮有缓存标记，第二轮发回去的第一轮回复留着字、没有思考块。
- 从 Aelios 过的那几条规矩（`node test/via-aelios.mjs`）5 项：模型名怎么改写、哪个走 Messages；身份怎么放进地址；她说的话是她的，定时和交接信那一轮（包括里面调了工具之后的请求）标成不是她说的，旧的中文提示也认。
- 发给 Claude 前的整理（`node test/claude-run.mjs`）4 项：system 合成一段；之前几轮的思考块拿掉、回复和工具调用留着、这一轮工具之间的思考留着、只有思考的那条整条去掉；第一轮和没思考块的原样发；别家模型不动。另外用真的 AI SDK 和 Cloudflare provider 核过：不整理时历史里的思考块会带着签名发出去，整理后没有。
- 交接信收哪些聊天（`node test/fold.mjs`）9 项：中文一个字算 1 token、全角标点也算，思考不算，图片和工具调用、结果算；留最近 6000 token，从她的那条开始留，她连发的几条和回复不拆开；聊得少时不写信、不调模型；更早的信不再收一遍；写出来是空的就不收。
- 读网页（`node test/web.mjs`，不用起 Worker，网络全是假的）25 项：跳转先查再跟；跳到本机或内网（包括域名解析到内网）不跟；无限跳转会停；本机地址直接拒；JavaScript 空壳交给浏览器且不加载图片、浏览器里也拦内网 IP；没有浏览器时原样返回；404 和图片不送浏览器；读过的页面再问不重抓、同一页同一个问题连压缩结果也不重算；模型回 NOTHING_RELEVANT 的段落丢掉、只是提到这个词的留着；带问题的长页只留摘出来的部分（Qwen3 带 `/no_think`）；换成 Claude 之类的别家模型也能压、不带 `/no_think`；短页不送模型；回答里的 think 块去掉；模型挂了原样返回；工具超时会把模型调用一起取消；GBK 页面（GBK 在本地 workerd 里也核过能解）；带钥匙的网站：同一网站的跳转每一跳都带钥匙，跳去别的网站、http 都不带，工具说明里写着哪些网站有钥匙、不写钥匙本身；钥匙里的 Accept 之类会顶掉默认的同名头，不分大小写；Cloudflare Access 的登录页不读，没钥匙时说可以在设置页加，钥匙不对时说被拒了；带钥匙的页面再空也不交给浏览器，403 直接说钥匙被拒，带钥匙的 404 提醒可能是钥匙看不到（GitHub 对没权限的私库回 404），不带钥匙的 404 不提钥匙；DNS 查不到地址、只回 CNAME、回的不是合法 IP 都不读，`::1` 写成长串也认得是本机；每次读网页都重新查 DNS，同一次读的几跳共用一次。
- 带钥匙的网站（`node test/run.mjs sites`）3 项：设置页存上，列表只有网站和头的名字、没有值，没钥匙看不到；模型的读网页说明里有这个网站；http、本机、内网地址、空钥匙、Host 头、写不成「名字: 值」的都不收；`/status` 列出来；拿掉一个后说明跟着变。`node test/site-keys.mjs` 4 项测网站怎么认（只认 https、不带用户名密码、本机内网和 Access 登录页不收）、钥匙怎么认（一串、`Bearer xx`、`Bearer: xx` 都当 Bearer，冒号前后有没有空格、是不是全角都认，多行按名字，保留头不收，重复、太多、太长、带中文或全角符号的不收，粘多了的首尾空白去掉）、按主机名一字不差地配（子域名、端口、http 都不算）、存、换、拿掉、最多 10 个。`node test/web-ui.mjs` 测设置页的钥匙：一行一格的「名字 ： 值」拼成钥匙，半填的行不算，两个常用按钮填好名字、已粘的值留着，连名字一起粘的值去掉名字，Authorization 只粘一串时补上 Bearer。
- 别的 MCP（`node test/run.mjs mcp`，再 `mcp-2`）10 项 + 重启 1 项：设置页接一个不用 key 的，数出 2 个工具；模型拿到的说明截短了、叫 `title` 的参数还在；调一次读到结果；要 key 的不填接不上、也不留着，填了能用，key 不往回发；接不上的报错不留；要登录的给出授权链接，假的授权服务跳回 `/mcp/callback`，页面写「接好了」、换到 token、之后的请求带着它；聊天里说「接上」接上了；先读了网页再接的被拒；`/status` 列出来；聊天里断开、设置页断开；重启后不用重连就在，登录过的那个带着存下的 token 调得通。`node test/mcp-servers.mjs` 16 项测地址检查、名字、key 放哪个头、截短、工具名不撞、结果转文字、顺序固定、还没连上的服务列着上次的工具且和连上时一字不差、授权页转义、存下的工具清单有个数和大小上限（太大或绕成圈的参数说明那个工具丢掉）。
- 表情包（`node test/run.mjs stickers`）12 项：设置页传 zip 导入（没钥匙不收，不是 zip 的报错）；表情图只凭长长的随机 key 就能取，乱填的 404；贴 Telegram 贴纸包链接导入，图第一次从 Telegram 取、之后不再取，找不到的包、表情符号包、乱填的链接、本机地址的 zip 都报错；Telegram 上表情跟在话后面，第一次上传、之后用 file_id 发；只发一张表情时不再补「没说出话来」；一次回复第二张被拒；自己画一张，存进「mine」并在 Telegram 上当动图发；画的那张缓存热着时不进表情清单（工具说明不变），设置页一改就跟着进来；网页上那条回复下面显示表情，网页上说的话不往 Telegram 发；模型看得到开着的包里的每一张，关掉一个包或整个功能就看不到；设置页改「什么时候用」、删单张、删包；`/status` 那一行。`node test/stickers.mjs` 10 项测 zip 读法（中文文件名、GBK 文件名、`__MACOSX`、加密的拒收、解开后太大的停下）、pack.json 和没有 pack.json 时的读法、名字不撞、Telegram 链接、画出来的 GIF 用解码器读回来每个像素都对、透明色和描边。
- 语音条（`node test/run.mjs voice`，三家都用假的服务商）11 项：没选服务商时你的语音条照样进模型（本地没有 AI 绑定，所以是「没听清」），模型拿不到 `send_voice`、提示词里没有语音的话；选了 ElevenLabs 没填声音时 `/status` 说缺 `VOICE_ID`、还是没有工具；填好后你的语音条由 Scribe 转成文字，回复整段做成一条语音发出去，显示「正在录音」，不再发文字；打字的照常回字；模型拿到 `send_voice` 和方括号写法，发完一条不补「没说出话来」；老模型不教标记；OpenRouter 上 Gemini 的模型教尖括号、`send_voice` 能带「怎么说」，`always` 时每条都按 OpenAI 格式要 MP3；服务商报错时照常发字、`/status` 写着为什么；带链接的说完再发链接、不带标记；Cartesia 带版本头、默认 `sonic-3.6`、按字认出中文；网页上显示「🎤 0:03」。`node test/voice.mjs` 10 项测 AI Gateway 的地址（三家各自的端点，没填 key 时不带 key 让 Gateway 用存的那把）、不是 MP3 的拒收、Whisper 和 Scribe 退回 Whisper、语音条怎么并进你的消息、MP3 时长、去掉链接和 emoji、每家的标记和去标记、缺什么设置、靠 Gateway 里存的 key 却被拒时报错写明是哪个 Gateway。`node test/web-ui.mjs` 测设置页选了服务商才显示语音那几项、按服务商给模型按钮和说明，目录每栏那行小字、「要填」和 Cloudflare 变量名的标记、返回一次退一层，「AI Gateway 的名字」只在「供应商」一处。
- 云端 Claude Code（`node test/run.mjs tasks`，定时任务的触发器是假的）12 项：默认关着，填了网址和 token 也没有 `cloud_task`，打开才有；不是触发器的网址不收，token 不往回发；设置页给出的提示词里是住户自己的地址和回报的写法，没钥匙看不到；Telegram 上叫它派活，触发请求带着 token 和两个头，单子开头是 task、code、title、仓库，里面没有她说的话，回复里有会话链接、没有暗号；网页上那条回复下面有卡片，设置页列着，看不到单子正文和暗号；暗号错、空、任务不存在都 403，不是 JSON 400，太大 413；进度来了卡片变「在干活」；结果状态不对、没写内容的不收，收下后住户自己起一轮在 Telegram 上说，提示那一轮的话不显示成她说的，卡片「做完了」，只留 https 链接，这一轮照常记进 Aelios；接着派带上上一单的结果、链接和仓库；一次回复第三单被拒；这一轮读过网页就不派；token 错、触发太频繁都说明原因，不记这一单；设置页「试一下」派一单测试，交回来不起一轮；`/status` 那一行；24 小时第 11 单在设置页和聊天里都被拒。`tasks-quiet` 2 项：一直不交回的，到点住户告诉她并附上链接，之后再交回来照样说；一直在报进度的不算没回音。`node test/cloud-tasks.mjs` 10 项测触发网址（别的域名、少了 `/fire`、带参数都不收，不对的地址一个请求都不发）、请求头和 body、各种失败的中文说明、提示词里该有的规矩、单子和接着派的写法、结果和进度怎么读、提示那一轮的话、暗号要整串对上且 7 天作废、进度在一小时内就多等最多 12 小时、一单最多说 5 次、测试单不说、进度最多 60 行、只留最新 200 单。
